# 🎣 보트 낚시 (Clearwater Fishing)

맑은 호수 위 보트에서 즐기는 브라우저 낚시 게임입니다. 설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다
(WebGL2 필요, 로컬 파일(file://)에서도 동작).

물 렌더링은 [Clearwater](https://github.com/Aureliengmz/clearwater)(MIT)를 바탕으로 합니다. FFT 파도, 굴절 코스틱,
프레넬 반사, 햇빛 반짝임, 인터랙티브 파문 위에 물고기·루어·찌·보트 선체·낚싯줄을 물속에서 직접 레이트레이싱해서
굴절/흡수/코스틱 조명이 물고기에도 그대로 적용됩니다.

## 모드

- **🎣 낚시 모드** — 보트에 앉아 캐스팅하고 낚시합니다.
- **⛵ 보트 모드** (대기 상태에서 `Tab`) — W/S로 전진·후진, A/D로 방향, 드래그로 시점, 휠로 줌.
  어탐기(왼쪽 아래)에 수심과 어군이 표시됩니다. 여울(얕은 곳)에서는 배가 걸립니다. 원하는 곳에서 `Tab`을 눌러 다시 낚시하세요.
- **🗺 세계 지도** (`M`) — 세계 지도에서 명소(소양호, 제주, 몰디브, 아마존, 로포텐 등 15곳)나 **아무 바다·육지(호수)나 클릭**해 이동합니다.
  위도와 바다/육지 여부로 지역이 정해집니다: 열대·온대·한대 × 바다/민물 7개 생태권, 어종 33종.
  지역마다 물빛, 수심 분포, 바닥(모래/자갈/진흙), 해 높이가 다릅니다. **깊은 곳일수록 물빛이 짙은 파란색**이 되고, 얕은 여울은 옥빛으로 밝게 보입니다.

## 공략법 · 퀘스트 · 상점

- **어종별 공략법이 실제 낚시 자료를 따릅니다.** FishBase, takemefishing.org, 미국 주 정부 낚시 가이드(MN·MO DNR, FWC, ODFW), NOAA,
  낚시춘추 등에서 어종별 **서식 수심·수층(바닥/중층/수면)·먹이 활동 시간(새벽/낮/해질녘/밤)·선호 미끼와 루어 순위·감기 속도**를 조사해
  `js/ecology.js`에 담았습니다(출처 URL 포함, 확인이 어려운 21종은 일반적인 낚시 지식으로 채우고 `verified:false` 표시).
  입질 확률 = 미끼/루어 선호도 × 수심 적합도 × 시간대 활성도 × 원줄 굵기(예민한 어종) × 감기 속도 — 공략법에서 벗어날수록 확률이 뚝 떨어집니다.
  깊은 곳에 사는 어종은 얕은 곳에서는 거의 나타나지 않으니, 어탐기로 수심을 찾아가세요.
- **🎯 공략도** — 현재 퀘스트 대상어에 대해 지금 채비가 얼마나 맞는지 별점과 가장 부족한 요소(수심/미끼/시간/감기 속도)를 알려 줍니다.
- **📜 퀘스트 (Q)** — 대상어 N마리, ○○cm 이상, ○kg 이상, 특정 시간대(예: 밤에 뱀장어), 고래·거북 목격 등. 완료하면 코인 보상.
- **🛒 상점 (P)** — 낚싯대(캐스팅·장력), 릴(감기 속도), 원줄(강도, 대신 예민한 어종 입질↓), 바늘(챔질 여유·바늘 빠짐), 어탐기(크기 색·어종 표시), 엔진(속도)
  업그레이드와 생선 토막·살아있는 미끼·포퍼·메탈지그·빅게임 루어 구매.
- **⏰ 시간** — 하루가 흐르며(게임 1시간 = 45초) 새벽·낮·해질녘·밤이 바뀌고, 밤에는 달빛과 별이 뜹니다. `T`로 다음 시간대로 넘길 수 있습니다.
- **희귀 방문자** — 매우 낮은 확률로 혹등고래·범고래·고래상어·대왕쥐가오리·바다거북·돌고래·개복치·상어·철갑상어·피라루쿠 등이 근처를 지나갑니다.
  화면에 잡히면 **목격**으로 도감에 기록되고 보너스 코인을 받습니다(고래·가오리·거북은 관찰만 가능). 상어·개복치·다랑어 등은 공략법이 맞으면 물기도 합니다.
- 진행 상황(코인, 장비, 도감, 퀘스트)은 브라우저에 자동 저장됩니다.

## 플레이 방법

| 채비 | 설명 |
| --- | --- |
| **대낚시** | 릴 없는 긴 낚싯대 + 찌. 미끼(떡밥·지렁이·새우)를 찌 수심에 맞춰 드리우고 찌의 움직임을 보고 챔질합니다. |
| **루어** | 스피닝 릴 + 루어(미노우·스푼·소프트웜). 마우스를 누르고 있으면 릴을 감고, 감다 멈추기로 액션을 줍니다. |

1. **캐스팅** — 좌클릭을 길게 눌러 힘을 모았다가 놓으면 던집니다. 채비가 떨어진 곳으로 카메라가 이동합니다.
2. **입질** — 물고기가 헤엄쳐 다니다 미끼/루어에 관심을 보이고, 살펴본 뒤 물지 말지를 확률적으로 결정합니다
   (어종별 선호 미끼, 수심, 경계심, 크기 반영).
   - 대낚시: 톡톡 건드리는 예신 뒤, 붕어·잉어는 찌를 **올리고**, 다른 어종은 찌를 **끌고 들어갑니다** → 그때 클릭(챔질).
     너무 일찍 채면 헛챔질, 늦으면 미끼만 따먹힙니다.
   - 루어: 쫓아오던 물고기가 덥석 물면(바이트) 바로 감아야 걸립니다. 멈췄다 감는 순간, 가라앉는 순간에 잘 뭅니다.
3. **파이팅** — 화면 중앙 원에 물고기가 달리는 방향(빨간 화살표)이 표시됩니다. 마우스를 **반대 방향**으로 두면
   물고기의 머리를 돌리며 힘을 뺄 수 있고, 같은 방향으로 끌면 장력이 치솟습니다.
   - 루어: 마우스 누르기 = 릴 감기, **휠 = 드랙 조임/풀기**. 장력이 드랙보다 크면 줄이 풀려 나갑니다.
     드랙을 너무 조이면 줄이 터지고, 너무 풀면 끝없이 끌려갑니다.
   - 대낚시: 릴이 없어 줄을 내줄 수 없습니다. 낚싯대 탄력으로 버티며, 마우스 누르기 = 들어올리기.
   - 물고기 힘이 빠지면(초록 바) 보트 가까이 끌어와 랜딩합니다. 줄이 너무 느슨하면 바늘이 빠집니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 (길게) | 캐스팅 / 챔질 / 릴 감기·들어올리기 |
| 마우스 위치 | 파이팅 중 낚싯대를 버티는 방향 |
| 휠 | 루어: 드랙 조임(↑)·풀기(↓) · 대낚시: 찌 수심 |
| 우클릭 드래그, A/D, W/S | 방향·시점 회전 (보트 모드: W/S 전진·후진, A/D 조향) |
| Tab | 낚시 모드 ↔ 보트 모드 |
| M | 세계 지도 |
| Q / P / T | 퀘스트 / 상점 / 다음 시간대 |
| 1 / 2 | 대낚시 / 루어 |
| B | 미끼·루어 교체 |
| R | 채비 회수 |
| H | 입질 표시 도움말 켜기/끄기 |
| Space | 좌클릭 대용 |

### 모바일 (터치)

휴대폰·태블릿에서는 자동으로 터치 조작이 켜집니다 (가벼운 렌더링 모드도 자동 적용, `?full`로 해제).

| 터치 | 동작 |
| --- | --- |
| 왼쪽 아래 **조그** | 낚시: 던질 방향 · 대기 중: 시점 회전 · **파이팅: 낚싯대를 버티는 방향**(물고기 반대쪽으로) · 보트: 위=전진, 아래=후진, 좌우=조향 |
| 오른쪽 아래 **큰 버튼** | 상황에 따라 바뀜 — 던지기(길게 눌렀다 놓기) / 챔질 / 감기·들기(누르고 있기) / 계속 / ⚓ 낚시 |
| **+ / −** | 루어: 드랙 · 대낚시: 찌 수심 · 보트: 줌 |
| ⛵ / 🎣, 🗺 | 보트·낚시 전환, 세계 지도 (지도는 드래그 이동, +/− 확대) |
| 화면 드래그 | 시점 회전 · 대기 중 화면 탭 = 챔질 |
| 채비 ▾ | 대낚시/루어, 미끼 선택 |

## 어종

온대 민물(붕어·잉어·배스·쏘가리…), 북미 민물(강꼬치고기·월아이…), 한대 민물(곤들매기·왕연어…), 열대 민물(피콕배스·피라냐·아로와나·나일퍼치…),
온대 바다(우럭·광어·참돔·농어·감성돔·고등어), 열대 바다(GT·바라쿠다·그루퍼·만새기·비늘돔…), 한대 바다(대구·핼리벗·명태) — 어종마다 선호 미끼, 활동 수심, 힘, 지구력, 입질 방식이 다릅니다.
바다에서는 미끼가 크릴·청갯지렁이·오징어살이 되고 원줄이 굵어집니다.
잡은 물고기는 오른쪽 위 살림망과 도감에 기록됩니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | HUD/UI 레이아웃 |
| `js/renderer.js` | Clearwater 기반 물 렌더러 + 수중 오브젝트 레이트레이싱 + 보트/낚싯대/찌 래스터 |
| `js/game.js` | 게임 상태, 캐스팅, 물고기 AI, 입질·파이팅, 카메라, HUD |
| `js/data.js` | 어종(외형·힘), 생태권, 물 종류, 명소, 미끼·루어, 상점 장비 |
| `js/ecology.js` | 조사한 어종별 생태·공략 데이터(수심, 시간대, 미끼·루어 순위, 감기 속도, 팁, 출처) |
| `js/world.js` | 세계 해안선 폴리곤 (Natural Earth 1:50m) |
| `js/pebbles.js` | 호수 바닥 자갈 텍스처(base64) |
| `img/fish/` | 어종별 실사진과 출처(`credits.js`) |

URL 옵션: `?visit=humpback` (방문자 강제 등장, 테스트용), `?debug` (FPS 표시), `?lite` (저사양: 코스틱 해상도↓, 글레어 끔), `?q=0.6` (렌더 해상도 배율).
